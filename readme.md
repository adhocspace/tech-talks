# TechTalks

Event resources for the TechTalks community: code examples, slides, and supporting materials from past and upcoming events.

TechTalks is hosted by adhocSpace — a community space for builders and makers, with a goal to grow Edinburgh’s tech community.

**Event folder structure**
```
tech-talks-N-<theme>/
  talk1-<speaker-name>/
    <talk-title>.pdf
  talk2-<speaker-name>/
    <talk-title>.pdf
```

**Contributing**
- Add materials in the relevant event folder.
- Keep file names clear and consistent (speaker-name_topic or talk-title).
- If sharing code, include setup/run instructions in the event `README.md`.

If you send the website and social links, I’ll replace the `TBD` values.
